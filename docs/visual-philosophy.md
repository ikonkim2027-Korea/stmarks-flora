# Field Atlas

Field Atlas reads as a warm, modern field companion rather than a herbarium sheet. The page rests on a soft sage canvas, and content sits on floating white cards with generous radii, so the interface feels lit from within rather than ruled into boxes. Nothing is fenced off by hard outlines. Where a v1 layout would have drawn a border, v2 separates with a tint shift, a shadow, or plain breathing room, and the result should feel calm, current, and easy to scan on a phone held in one hand outdoors.

Colour is a status system on a single botanical scale. Moss carries structure and primary emphasis, sprout marks what is live right now, clay flags anything invasive or cautionary, mist handles neutral or observation-only states, and sage fills the quiet middle. Every badge is a pill drawn from that scale through the chip primitive, never a default utility swatch. Habitats read on one moss-to-sprout ramp rather than a per-habitat hue, so a page of nine habitats still looks like one object. Avoid introducing new hues; if something needs emphasis, reach for weight, size, or tint before reaching for a new colour.

Geometry is round and consistent. Cards use the 22px card radius, inner tiles and callouts use the 16px tile radius, and anything interactive that is not a card is a full pill: buttons, chips, filter controls, and search fields alike. Repeating this small vocabulary is what makes unfamiliar pages feel like part of the same guide.

Typography stays quiet. Weights are capped between 400 and 600, so headings earn their presence through size and tight tracking instead of black weight. Uppercase wide-tracked labels belong to v1; the section label class handles small headers now. Taxonomy is the one flourish: scientific names are set in italic serif, which keeps binomials legible as names and gives each specimen record a botanical signature.

Restraint is the signature. Status is a dot or a pill, never an emoji. Density is welcome where data is dense, such as the season grid, provided the marks stay on the same dot language used elsewhere. When in doubt, remove a border, soften a colour, and let the card do the work.
